# База даних Firebase: перевірка з'єднання й правила доступу

Усі задачі, бали й профіль зберігаються в **Firebase Realtime Database**. Якщо додаток показує червону смугу
«Немає зв'язку із сервером», задачі не з'являються, а Налаштування «зависають», причина майже завжди тут.

## 1. Швидка перевірка адреси бази (1 хвилина)

Адреса бази записана в `app/google-services.json`, поле `firebase_url`. Відкрийте її в браузері, додавши в кінці `/.json`:

```
https://todolist-3e189-default-rtdb.europe-west1.firebasedatabase.app/.json
```

(підставте свою адресу з `firebase_url`). Що ви побачите:

| Відповідь у браузері | Що це означає |
|---|---|
| `{"error" : "Permission denied"}` | **Усе гаразд.** База існує, правила доступу діють. Якщо додаток усе одно «без зв'язку», проблема в мережі телефона (VPN, фаєрвол, приватний DNS): спробуйте інший Wi-Fi або мобільний інтернет |
| `{"error" : "The Firebase database '…' has been deactivated."}` | База **вимкнена** на боці Firebase. Додаток не працюватиме, доки її не ввімкнуть: консоль Firebase → Build → Realtime Database (шукайте повідомлення з кнопкою відновлення), а якщо її немає — метод REST API `projects.locations.instances.reenable` або підтримка Firebase |
| Текст «Firebase error. Please ensure that you have the URL of your Firebase Realtime Database instance configured correctly.» або сторінка 404 | У проєкті **немає бази за цією адресою** (не створена, видалена або створена в іншому регіоні). Див. розділ 2 |
| Текст «Database lives in a different region…» з правильною адресою | База створена в іншому регіоні. Див. розділ 2, п. 4 |
| Показано дані (JSON із Tasks/Users/Stats) | База **відкрита для всіх**: це небезпечно. Негайно застосуйте правила з розділу 3 |

Ту саму перевірку робить сам додаток: торкніться червоної смуги, і він покаже адресу, стан мережі й відповідь сервера.

## 2. Якщо бази немає (або вона в іншому регіоні)

1. Firebase Console → ваш проєкт → **Build → Realtime Database** → **Create Database**.
2. Оберіть регіон. Запам'ятайте його: адреса залежить від регіону.
3. Режим правил оберіть **locked mode**, далі застосуйте правила з розділу 3.
4. Завантажте **новий `google-services.json`**: Project settings → Your apps → `com.example.todolist` → Download. У новому файлі `firebase_url` має збігатися з адресою створеної бази. Замініть файл `app/google-services.json`, закомітьте й випустіть нову версію (`git tag v1.4.1`…).

Без нового `google-services.json` додаток і далі звертатиметься до старої адреси.

## 3. Правила доступу

Realtime Database → вкладка **Rules** → вставте вміст файлу `docs/firebase-rules.json` → **Publish**.
Вони дозволяють кожному користувачеві читати й писати лише власні дані та перевіряють формат записів.

**Після кожного оновлення додатка перевіряйте, чи змінився файл правил.** У версії 1.5.0 до правил додано поля задачі `notes`, `repeat`, `subtasks` і вузол `Activity` (скільки задач виконано за день, для графіків статистики). Без нових правил база відхилятиме збереження задач із цими полями.

### Перевірка, що база не відкрита всім

Відкрийте в браузері `https://<ваша-база>.firebasedatabase.app/.json`. Правильна відповідь: `{"error" : "Permission denied"}`. Якщо замість цього показано дані, правила відкриті: будь-хто, хто знає адресу, може читати й змінювати базу. Негайно опублікуйте правила з цього розділу.

### Старі записи з паролями

Найперші версії додатка записували пароль відкритим текстом у `Users/<uid>/password`. Справжні паролі зберігає Firebase Authentication, ці копії не потрібні. Нові версії поле не створюють і прибирають його з профілю користувача при вході; ті, хто не заходитиме, видаліть вручну (Realtime Database → Data → `Users` → запис → `password` → ✕).

## Як додаток поводиться без зв'язку

- Нова задача одразу з'являється в списку й зберігається на телефоні; сервер отримає її, коли зв'язок з'явиться.
  Повідомлення «Збережено на телефоні» нагадує, що це ще не онлайн.
- Інші дії (позначити виконаною, видалити) надійно працюють лише після першого успішного з'єднання.
- Налаштування відкриваються одразу; збережені імена підтягуються, щойно база відповість.
