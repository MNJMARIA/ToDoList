# Звіти про збої (Firebase Crashlytics)

Додаток надсилає у Firebase звіт, коли він вилітає, а також коли база даних повертає помилку
(наприклад, «Permission denied» при створенні завдання). Так ви бачите проблему, навіть якщо користувач
про неї не написав.

## Що надсилається
Стек помилки, модель телефона, версія Android і версія додатка. Електронна пошта, назви завдань і
пароль **не** надсилаються, ідентифікатор користувача не задається.
Збірки для розробки (debug) нічого не надсилають.

## Одноразове налаштування (2 хвилини)
1. [Firebase Console](https://console.firebase.google.com) → ваш проєкт → **Build / Release & Monitor → Crashlytics**.
2. Натисніть **Enable Crashlytics** (якщо кнопка є). Новий `google-services.json` завантажувати **не потрібно**.
3. Випустіть версію (`git tag v1.3.0 && git push origin v1.3.0`), встановіть її на телефон і відкрийте додаток.
4. Перший звіт з'являється в консолі через кілька хвилин після **наступного** запуску додатка
   (звіти відправляються при старті).

## Як перевірити, що працює
Згідно з документацією Firebase, налаштування в консолі не завершується, доки не прийде перший звіт про збій.
Тому в додатку є прихований тестовий збій:

1. Встановіть версію додатка з Crashlytics (не debug-збірку з Android Studio, вона нічого не надсилає).
2. Відкрийте **Меню → Про додаток** і **довго натисніть** на рядок із версією.
3. Підтвердіть у діалозі: додаток закриється.
4. **Відкрийте додаток знову з інтернетом**: звіт відправляється при наступному запуску.
5. У консолі Firebase → Crashlytics через кілька хвилин (іноді довше) з'явиться збій «Crashlytics test crash».

«Тихі» помилки бази видно у вкладці **Non-fatals**. Якщо за 5–10 хвилин нічого немає, перевірте, що інтернет був
і що це не debug-збірка.

## Вимкнути
Видаліть рядок `firebase-crashlytics` з `app/build.gradle` і плагін `com.google.firebase.crashlytics`.
